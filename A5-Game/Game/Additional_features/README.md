# Additional Features Reminder


## Where to push your work

Once your feature is developed and tested, please push it to the branch:

```text
Game_additional_features
```

## Where to place additional files

Please place all additional files in:

```text
APBC2026/A5-Game/Game/Additional_features
```

## Important implementation rule

Please do **not** modify the core of the game unless this is explicitly required.

Try to implement your feature as separately as possible. It is fine to connect it to the game through:

- function calls
- additional flags
- small tweaks

The goal is to keep extra functionality modular, easy to test, and easy to remove or review if needed.

## Don't forget to attach README

Describe what a new functionality does, and doesn't. Give an example on how to execute it.
